## Project Overview

GREY PITORI is a South African lifestyle brand inspired by Pretoria, also known as Pitori. The brand represents the intersection of people, cultures, perspectives and ambition.

The website is designed to provide visitors with information about the GREY PITORI brand, showcase its products and lookbook, introduce the brand's story, and provide visitors with a way to get in contact with the business.
## Website Goals and Objectives
- Create an online presence for GREY PITORI.
- Showcase GREY PITORI products.
- Allow users to explore the brand's story.
- Display the brand's lookbook.
- Encourage customers to shop the products.
- Provide visitors with contact information.
- Create a professional and user-friendly website.
## Key Features and Functionality

- Home page with GREY PITORI branding.
- Navigation menu linking to the main website pages.
- Shop page for displaying products.
- Our Story page explaining the brand.
- Lookbook page showcasing the brand's visual style.
- Join the Icons page for visitors interested in joining the brand community.
- Contact Us page for customer enquiries.
- Shop Now button linking users to the Shop page.
- Product images and descriptions.
